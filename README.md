# Hospital Management System - UI/UX Design

A comprehensive frontend UI/UX prototype designed to streamline hospital operations, patient management, and doctor scheduling.

---

## 🎨 Project Overview
This repository contains the complete design assets and raw `.fig` source files for the Hospital Management System. The interfaces were designed with a mobile-first approach to ensure accessibility for patients and medical staff on the go.

### Key Features Designed:
* **Patient Dashboard:** Interface for appointment booking and medical record access.
* **Doctor Portal:** Schedule management and patient overview screens.
* **Admin Panel:** Centralized hub for hospital resource management.
